Comment lire cette page

Tous les voyages sont mélangés. Pour pouvoir les comparer, chaque prix aller-retour est exprimé en % au-dessus du prix le plus bas jamais vu pour la même combinaison de dates (0 % = le meilleur prix observé). Plus la barre est basse, plus c'était un bon moment pour chercher. n = nombre d'observations : en dessous de , le résultat est grisé car il repose sur trop peu de données pour conclure.
